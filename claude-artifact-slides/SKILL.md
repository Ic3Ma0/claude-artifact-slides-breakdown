# Claude Artifact Slides · 交互演示

用户给了主题即可开始。保留指定语言、受众、时长、论点和素材。在只有主题时，选一个具体的听众问题，把假定的受众和时长在交付时说明。

## 从讲稿到舞台

1. 确定听众进场时相信什么，离开时能解释什么。把中间的关键变化写成简短的场景表：讲者说什么、画面里哪个物体会发生什么变化、下一次按键揭示什么。把依据和复杂解释留给讲者备注，台上只保留此刻需要读的字。
2. 选一个属于本主题的实体或具体操作贯穿全场。让观众至少一次亲眼看到因果关系。可让讲者改变一个量、放大一个位置或并列两个结果。选择能看出前后差异的参数；图解若使用夸张比例，在备注里说明。一个转场可以沿用上一幕中已有的边缘、颜色或运动方向，把观众带进下一幕。
3. 复制本 Skill 的 assets/vinyl.html 到用户的交付目录，作为单文件演示骨架。保留前进后退、按键、自动播放、备注、响应式布局和减少动态效果支持。替换页面标题、节拍数组、视觉绘制函数、交互控件与无障碍标签。按主题选择 DOM、Canvas 2D 或 WebGL；若深度遮挡、绕行观察是论证的一部分，再使用真正的三维几何。交付离线版时将用到的库、字体和资产打包在本地。
4. 把舞台做完，交付能打开的 HTML。以新主题开场和结束；逐步检查每个节拍的画面和备注，至少回退一次，操作关键交互，验证自动播放到末尾会停、窄屏可读。对外演示前检查舞台上没有示例主题遗留的按钮或单位。

**可直接运行的样例。** assets/vinyl.html 用唱片、放大后的沟槽和扫描轨迹讲机械播放。抽走“唱片”后，新作品仍需有自己的图景。例如讲“城市为什么会堵车”，可用同一条环路完成三步：等距行驶、让一辆车轻点刹车、看减速波如何向后传播。此时控件应改变刹车动作，声音样例里的转速滑块应该移除。

**研究或复刻原作的表达方式时**，阅读 references/case-study.md。里面有原作 13 场的安排、43 个节拍的分布、转场与声音的证据，以及 rea-video 在取样分析中的作用。生成新演示所需的资源均在本包内。

**演示样例本身时**，直接给出 assets/vinyl.html 的可打开链接和按键提示。若用户指定要演示 The Last Boring Slide 原作，提供 references/case-study.md 末尾的作者分享页。
